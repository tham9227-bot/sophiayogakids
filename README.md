# Sophia Yoga Kids – sophiayogakids.com

Website tĩnh (HTML/CSS/JS), không cần cài đặt gì, chạy miễn phí trên GitHub Pages.

## Các file chính
- `index.html` – trang chủ (menu, lớp học, giới thiệu, ý tưởng bài học, tài liệu, đăng ký)
- `bai-viet.html` – mẫu một bài giáo án; sao chép file này để viết bài mới
- `css/style.css` – màu sắc và giao diện (đổi màu ở đầu file, phần `:root`)
- `js/main.js` – menu điện thoại, lọc bài viết, form đăng ký
- `images/` – logo và ảnh. Thay `sophia-placeholder.svg` bằng ảnh thật của Sophia.

## Xem thử trên máy
Mở thư mục, bấm đúp vào `index.html` là xem được trong trình duyệt.
